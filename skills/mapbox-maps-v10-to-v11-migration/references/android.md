# Android: Maps SDK v10 → v11

Mappings for moving an Android app (Kotlin or Java, Views or Jetpack Compose) from Maps SDK v10 to v11.

**Requirements for v11:** read them from the release notes of the 11.x version you're targeting. They rose during the 11.x line. 11.0 needed compile SDK 33. Current 11.x is built with compile SDK 35 against `androidx.appcompat` 1.6.1 and `androidx.core:core-ktx` 1.9.0. Raise the app's compile SDK and AndroidX versions to at least what the targeted release was built with. Don't pin AndroidX libraries below that with `strictly(...)`: it downgrades libraries the SDK was compiled against.

**Views or Compose.** Both are supported. The Compose extension (`com.mapbox.extension:maps-compose`) is optional and new in v11. Migrate each map with the UI layer it already uses. Moving a View-based map to Compose isn't part of the migration.

**Minimum 11.x for target APIs.** The Target column assumes **11.13 or later**. Featureset Interactions (`ClickInteraction`, `LongClickInteraction`, `mapboxMap.addInteraction`) are stable since 11.13 and don't need an opt-in. `MapboxMap.addInteraction` still carries a leftover `@MapboxExperimental` annotation, which only produces a warning. Some Standard featuresets need newer versions (noted inline). On an older pinned 11.x, use the "older 11.x" fallback given in the row.

## No direct mapping

| ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Custom HTTP stack (`HttpServiceFactory.setUserDefined`, `HttpServiceFactory.reset`, `@MapboxModule` `CommonHttpClient`) | Removed from the public API. Listener types map one to one: `OnCameraChangeListener` → `CameraChangedCallback`, `OnMapIdleListener` → `MapIdleCallback`, `OnMapLoadErrorListener` → `MapLoadingErrorCallback`, `OnMapLoadedListener` → `MapLoadedCallback`, `OnStyleImageUnusedListener` → `StyleImageRemoveUnusedCallback`, and so on.

```kotlin
// v10
val listener = OnCameraChangeListener { onCameraChanged(mapboxMap.cameraState) }
mapboxMap.addOnCameraChangeListener(listener)
// ... later
mapboxMap.removeOnCameraChangeListener(listener)

// v11
private var cameraSubscription: Cancelable? = null
cameraSubscription = mapboxMap.subscribeCameraChanged { event ->
    onCameraChanged(event.cameraState)
}
// ... later
cameraSubscription?.cancel()
```

`Cancelable` here is `com.mapbox.common.Cancelable`.

```kotlin
            boolean { featureState { literal("selected") }; literal(false) }
            literal("#ff0000")
            literal("#888888")
        }
    )
}

// On tap: set state (callback is required, returns Cancelable)
mapboxMap.setFeatureState(
    sourceId = SOURCE_ID,
    featureId = tappedId,
    state = Value(hashMapOf("selected" to Value(true))),
) { }
```

Preconditions: features need ids (integer, or a string castable to one); feature state works on **paint** properties only; updates are asynchronous. If a precondition fails (for example a layout property changes on selection), keep the source update and note why in the report.

## Removed in v11

APIs that were deprecated in v10 and removed in v11. A v10 app that still uses them needs more than a rename.

| Removed                                                                                                          | Use instead                                                                                    |
| ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `MapboxMap.queryRenderedFeatures` overloads taking a screen coordinate or box directly, `queryFeatureExtensions` | `queryRenderedFeatures(RenderedQueryGeometry, RenderedQueryOptions)`, or interactions for taps |
| `MapboxMap.isFullyLoaded`, `MapStyleStateDelegate.isFullyLoaded`                                                 | `Style.isStyleLoaded`                                                                          |
| `GeoJsonSource` public constructor                                                                               | `geoJsonSource(id) { }` or `GeoJsonSource.Builder`                                             |
| `backgroundPatternTransition`, `lineDasharrayTransition`, `linePatternTransition`, `fillPatternTransition`       | Remove                                                                                         |
| `MapboxMap.subscribe(observer, events)` / `unsubscribe`                                                          | `subscribe<Event>` methods                                                                     |
| `MapView.location2`, `LocationConsumer2`                                                                         | `MapView.location`, `LocationConsumer`                                                         |
| `Style.setStyleGeoJSONSourceData`                                                                                | `GeoJsonSource.featureCollection(...)` or partial updates                                      |
| Experimental `setRenderCacheOptions` / `getRenderCacheOptions`                                                   | Remove                                                                                         |
